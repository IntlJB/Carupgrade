# Om Os Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Byg en personlig, SEO-optimeret Om Os-side og placer menupunktet “Om Os” mellem “Reparationer” og “FAQ” på hele hjemmesiden.

**Architecture:** Projektet er et statisk HTML-site. Den nye side oprettes som `om-os/index.html` med samme indlejrede CSS-, navigations- og footerstruktur som FAQ-siden, mens integrationstesten udvides til at kontrollere indhold, SEO og navigation på tværs af alle HTML-sider.

**Tech Stack:** HTML5, CSS3, JSON-LD, Node.js test runner, `node:fs/promises`, regulære udtryk.

---

## Filstruktur

- Opret `om-os/index.html`: Selvstændig Om Os-side med metadata, JSON-LD, navigation, historie, tidslinje, værdier, CTA og footer.
- Rediger `tests/html-integration.test.mjs`: Test sidekrav og fælles navigationsrækkefølge før implementering.
- Rediger de seks eksisterende sider, hvor hovednavigationen indeholder både Reparationer og FAQ: Indsæt `/om-os/` mellem dem og opdater relevante footer-links.
- Rediger `sitemap.xml`: Tilføj den kanoniske Om Os-URL.

test('main navigation places Om Os between Reparationer and FAQ', async () => {
  const files = await findHtmlFiles();

    const html = await readFile(file, 'utf8');
    const nav = html.match(/<nav[^>]*(?:id="navbar"|class="topbar")[\s\S]*?<\/nav>/)?.[0];

    assert.match(nav, /Reparationer[\s\S]*?href="\/om-os\/"[^>]*>Om Os<\/a>[\s\S]*?FAQ/, file);

### Task 2: Byg Om Os-siden

Tilføj dansk HTML5-markup med unik title og description, canonical `https://carupgrade.dk/om-os/`, cookie-assets, fonts, Open Graph/Twitter-felter og JSON-LD-graf med `Organization`, `AboutPage` og `BreadcrumbList`. `AboutPage` skal indeholde:

  "url": "https://carupgrade.dk/om-os/",

- [ ] **Step 2: Implementer responsive styles i eksisterende designsprog**
